# 試作仕様と次の設計

## 目的

就学前から中学へつながる図形学習のうち、最初に描画品質・操作・予想と確認の学習ループを評価する。学年による進級や速さによる競争は導入しない。

失敗しても星を減らさない。ヒントの使用で報酬を減らさない。同じ課題の反復を新しい発見として重複記録しない。

## 数学モデル

### 平面

形はローカル頂点＋平行移動＋回転で表す。正方形を覆う課題では、面積の不足・ピースの重なり・はみ出しを別々に計算する。L字課題は凹多角形の頂点列の一致を判定する。採点に画面ピクセルや見た目の近似画像は使わない。

### 積み木

座標はx=右、y=上、z=正面側。整数格子に１辺１の立方体を配置する。上のブロックには真下の支持が必要。正面の画面座標は(x,y)、右側面は(-z,y)、上面は(x,-z)。同じ位置へ投影されるブロックはシルエットでは１セルになる。

### 見本制作と自由制作

- ３×３の床、最大３段。場所ボタンは常に上から見た配置で、奥から手前へzが増える。黄色の原点マーカーと手前の線を両画面でそろえる。
- 見本と制作の視点は同時に切り替える。制作画面ではカメラのドラッグを使わず、４つの向きで比較する。
- 場所を押すと、その列の最上段へ１個積む。「とる」では最上段だけを削除する。浮いた積み木を作れない。取り消しと、取り消せる全消去を用意。
- 判定はブロックの整数座標集合が見本と一致すること。個数や単一方向のシルエットだけで正解にしない。「同じ場所・高さ」を課題として明示する。
- 置くたびに正誤を表示せず、子どもが「見本とくらべる」を押して確かめる。ヒントは段表示と、異なる列を１つだけ示す支援。
- ４・６・８個の３見本を完成すると各１つ星を記録し、基地に作品を保存。同じ見本では星を重複しない。自由制作では正誤判定を使わず、１つの作品枠を更新する。
- 作品と各見本・自由制作の途中を別々に保存。「つづきを作る」は最新の制作途中を優先する。保存が禁止されている場合はページ内で保持し、画面を閉じるまでの保存であることを伝える。
- 基地は３×３の大きな床へ最大４作品を配置。同じ床へ重ねず、90度回転・移動・配置を外す操作に対応。作品は元データを保ち、向きと場所を別保存する。草の背景は初期、青は３発見、夕焼けは12発見で選べる。星は消費しない。

### 対称・拡大縮小・面積

対称のマスはセル中心を中央の軸で反射する。拡大縮小は同じ原点を基準に頂点を倍率倍する。辺の長さは倍率倍、面積は倍率の２乗倍。面積は頂点列の計算から求め、図の１cm²参照正方形と同じ描画縮尺を使う。答えは６・12・６cm²。

### 投影図からの復元

見本制作の全座標一致とは別に、支持・３×３×３の範囲・重複のない配置を検証し、正面(x,y)、右側面(-z,y)、上面(x,-z)の３集合を照合する。例えば「四角いひろば」は６個と８個の異なる建物がどちらも３投影に一致し、両方を正解にする。図の枠・軸を固定して、位置の違いを自動で打ち消さない。

### 箱

十字・ながいおび・ずれたおびの３種類。１辺１の面を共有辺のヒンジで90度折る。十字の例は、面１を中心に、２=右、３=左、４=上、５=下、６=４の上。閉じた中心は１=(0,0,0)、２=(.5,0,.5)、３=(-.5,0,.5)、４=(0,.5,.5)、５=(0,-.5,.5)、６=(0,0,1)。向かいの組は十字が1/6、2/3、4/5、おび２種は1/3、2/4、5/6。

このモデルを一般的な展開図ソルバーと扱わない。別の展開図や折る順番を増やす時は、それぞれの閉じた位置、接続、衝突を確認する。

体積は１辺１cmの単位立方体の数、表面積は隣接する積み木がない側の単位面の数から求める。３直方体の寸法は２×２×２、３×１×２、３×２×２cm。体積８・６・12cm³、表面積24・22・32cm²。説明では同じ広さの面が２つずつあることを示す。

### 回転体・切断

長方形の左辺、直角三角形の縦辺、半円の直径をy軸に合わせ、半径と高さの頂点を0〜360度で回す。掃引境界の三角形を生成し、部分回転では開始・終了の面も閉じる。円柱・円錐・球の３指定問題に限定する。

切断の立方体は[-1,1]³、平面はx+y+z=2、x−z=0、x+y+z=0。12辺との交点を重複除去し、平面上で順に並べて三角形・長方形・正六角形を得る。同じ交点を立体内の断面と正面から見た２D図へ使い、直交する平面基底で長さを保つ。任意の切断平面を選ぶ機能はまだない。

## 画面と操作

- 日本語の短い指示。文字が読めない子向けに、保護者との利用や任意の読み上げを用意。
- 回転・移動・視点・折り角度の操作欄を図形の右側に統一。狭い画面の平面パズルはピースと目標を縦に並べ、操作ボタンは44px以上を確保。
- 漢字のルビは `src/shared/furigana.ts` の読み辞書で管理し、動的なヒント・正解・記録にも付ける。文言を追加する際は辞書と読み方を確認する。読み上げにはルビを除いた元の文章を渡す。
- ピースのドラッグだけに依存せず、選択・配置と方向ボタンを用意。
- 積み木の視点と箱の折り角度はボタンでも操作可能。
- 動きを減らすOS設定では箱の自動開閉・回転体の掃引を即時切り替え。
- 保存形式はversion付き、壊れた保存や保存不可でも遊びを続ける。
- ゲーム切り替え時にイベント、アニメーション、3D描画資源を解放。

## 次の設計に使う観察

子どもに操作を教え過ぎず、どこで困ったかを見てから支援を入れる。

1. 指示の理解：何をするかを自分で捉えたか。
2. 操作：図形の理解と指の操作の難しさを区別できるか。
3. 予想：動かす前に、形や面の位置を予想したか。
4. 確認：予想と結果の違いを見直したか。
5. 新しい図：別の向き・別の建物でも同じ考え方を使ったか。

## 展開の順序

1. 実装済み：最初の３試作で、図形の誤表示と操作の問題を修正する。
2. 実装済み：ブロック建築に「見本をまねて作る」を加えて、観察から制作・確認までつなぐ。
3. 実装済み：自由制作・シルエット問題・基地の作品配置をつなぐ。
4. 限定課題セット実装済み：３展開図、対称、拡大縮小、面積・体積・表面積へ広げる。
5. 限定課題セット実装済み：投影図からの復元で、複数解を認める採点を使う。
6. 限定課題セット実装済み：専用の幾何計算と検証による回転体・切断。

次は実際の子どもの観察から指示・ヒント・難易度を調整し、初見の課題を増やす。41ミッションの完了を、全学年の習得の証明とは扱わない。

### 参考にする教材の考え方

こぐま会の公式説明では、体を使った経験、教具を使った試行錯誤、ペーパーワークという３段階を示している。[KUNOメソッドの説明](https://www.kogumakai.co.jp/kuno-method/basic.html)

公式の教材一覧でも、位置表象・図形などの領域に具体物、カード、ペーパー教材を用意している。[教具・教材一覧](https://www.kogumakai.co.jp/goods/list.html)、[具体物・カード教材](https://www.kogumakai.co.jp/goods/go/index.html)

本アプリでは、この考え方を参考に独自の図案・設問を作り、１つの題材を次の３つで構成する。

1. **実物でやる**：紙片、箱、手元の積み木や同じ大きさの物を使う短い遊び。大人向けの声掛けを１つ添える。
2. **画面で試す**：動かす、重ねる、積む。まず自由に触れ、次に動かす前の予想を促す。
3. **別の図で確かめる**：見たことのない配置や静止図で考える。回答用のボタンは使えるが、重ね合わせ・自由回転などの観察支援を使った場合は支援の記録を残す。

画面での操作だけで、実物の重さ、手触り、体の向きの経験まで済んだとは扱わない。就学前の教材では名称や公式の暗記を入口にせず、「どう置いたら合う？」「どこが同じ？」という行動を中心にする。

### 長く遊べる３本の道筋

| 道筋 | 就学前 → 小学校 → 中学 |
| --- | --- |
| ピースの道 | 形合わせ → 合成・分解 → 合同 → 面積 → 対称・拡大縮小 → 相似・根拠の説明 |
| 積み木の道 | まねる → 見えない部分 → 別方向の図 → 展開図 → 体積・表面積 → 投影復元・空間内の距離 |
| 場所の道 | 上下・前後 → 配置図 → 経路と回転 → 角・平行・垂直 → 図形の移動 → 位置関係の説明 |

各系統から「ひとつやさしく」「次の考え方」「自由に作る」を選べる。苦手な子は支援を増やして同じ考え方に触れられ、得意な子は別解や手がかりの少ない課題へ進める。学齢を上げることだけを進捗にしない。

１系統に12の基準課題を用意する計画。内訳は体験２、基礎４、応用４、初見確認２。体験課題は理解の評価には数えない。

| 対象 | 系統数 | １系統の基準課題 | 計画上の課題数 |
| --- | ---: | ---: | ---: |
| 就学前 | 18 | 12 | 216 |
| 小１～２ | 6 | 12 | 72 |
| 小３～４ | 6 | 12 | 72 |
| 小５～６ | 6 | 12 | 72 |
| 中学 | 6 | 12 | 72 |
| 合計 | 42 | 12 | 504 |

504は拡張後の目標で、現在の41に504を足した数ではない。既存課題も系統・課題IDを割り当てて整理し、同じ設問を重複計上しない。12課題の案は子どもの観察後に調整する。

色や数字だけを変えたものは反復用の変種として別計数にする。基準課題では、次のうち何を新しく考えるのかを明記する。

- 手がかり：全部見える → 一部 → 複数の図 → 必要な情報を選ぶ。
- 変換：移動 → 回転 → 裏返し → 倍率変更。
- 構成：２片 → 多片、同じ形 → 別の作り方。
- 見えなさ：重なり、裏側、内部。
- 解の数：１解 → 複数解 → 決めるための追加条件。
- 表現・支援：実物、操作図、格子、静止図、用語・式。

同じ４個の積み木でも、同じ場所にまねる、回した見本から作る、横の図だけでは決まらないと気付く、必要な２つ目の図を選ぶ、では考える内容が違う。

2. 体験：３個のL形をまねる。上からの格子を見ながら置く。
3. 基礎：４個の正方形を１段で作る。
4. 基礎：３個で高さ２の柱を含む形を作る。
5. 基礎：４個で高さ２の階段を作る。

### 教材を増やすための共通基盤

現在の各ラボに配列を追加するだけでは、説明と図形が食い違う危険がある。対称軸・三角形の説明の固定値、３×３×３の制作・保存上限、凸図形を前提とする面積交差計算などを、対象テンプレートの範囲に合わせて整理する。

課題データには次を持たせる。名称と学齢だけでは推薦や採点を決めない。

| 項目 | 内容 |
| --- | --- |
| ID・版 | 系統ID、課題ID、内容の版、生成テンプレートの版、再現用の乱数seed |
| 力・前提 | 識別、構成、回転、位置、比較、規則、視点などの能力タグと前提 |
| 区分 | 体験・基礎・応用・初見、練習と初見で共有しない配置グループ |
| 難易度 | ピース数、回転、隠れる量、視点数、格子などの支援、数値 |
| 幾何データ | 頂点、整数座標、寸法、軸、視点、許す操作と生成制約 |
| 指示・支援 | 短い指示、読み、読み上げ文、段階ヒント、実物遊び、声掛け |
| 判定・説明 | 同じパラメータから作る正解集合・解説。複数解の許可 |
| 接続 | ひとつやさしい課題、同じ力の別課題、次の系統 |

図形、判定、寸法表示、指示、ヒント、解説を同じデータから作る。制約付きの生成は、解の存在、範囲内への収まり、選択肢の重複、複数解、説明との一致を検査してから出題する。未検証の任意図形を大量に生成しない。

平面は共通座標をSVGに描き、３Dは幾何データからメッシュを作る。採点は幾何モデルを使う。２Dで十分に伝えられる課題は２Dを使い、立体と面を往復する課題に３Dを使う。現行の右側コントローラー、44px以上のボタン、全漢字のルビ、読み上げ、動きを減らす設定への対応を引き継ぐ。

### 記録とゲームの進み方

星・作品の報酬と、理解を確かめる記録を分ける。ヒントを使って完成しても同じ遊びの報酬を与える。

記録する候補は、課題ID・版、最初の予想、試行回数、支援の段階、完成、初見での結果、日を空けた再確認。既存の完了記録は残し、過去の41ミッションから未記録の予想や支援を推定しない。まず端末内の記録から始め、名前・学年の入力を必須にしない。

「お手伝いでできた」「別の図でも考えられた」「また確かめた」を区別して、大人が声掛けを選べるようにする。短い課題の正解だけで「習得済み」と断定しない。推薦はラボの番号順だけでなく、同じ能力のやさしい課題・初見課題・次の考え方から選ぶ。

子どもには「さわってみる」「考えてみる」「もっとむずかしく」を用意し、１回３～５問程度の短いセットを提案する。中断・再開を許し、速さの順位や失敗時の罰を設けない。先生・保護者には能力や支援量からセットを選ぶ入口と、観察項目・実物遊びを用意する。

### 実装と確認の順序

1. **共通課題データと移行**：既存41ミッションに安定したID・能力タグを付け、保存互換を保つ。図形と説明の固定値を整理する。
2. **就学前の最初の72課題**：上記６系統を、実物遊び・画面操作・初見確認の組として実装する。個別の幾何判定、ルビ、指示、狭い画面で確認する。
3. **子どもの観察と調整**：指示を理解したか、操作で困ったか、予想を変えたか、別の図でも考えたかを観察する。少人数の観察で学習効果を証明したとは扱わない。
4. **就学前の残りと小学校の入口**：比較・位置・構成から、角・面積・箱へつなぎ、基準課題を順に増やす。
5. **高学年・中学への拡張**：合同・対称・倍率・量、投影・回転体、根拠の説明へ広げる。数学モデルを追加する系統は別に検証する。
6. **42系統・504課題を目標に整備**：観察結果を反映して各系統を完成する。追加練習の生成数と、基準課題数を分けて表示する。

各ロットは、数学的な成立、回答と説明の一致、既存記録の互換、操作の代替、ルビ・読み上げ、320px幅での右側操作欄と図の収まりを確認する。学習面はブラウザテストと分け、実際の子どもがどこで迷うかを観察してから次のロットの難易度を決める。

## 拡張の初回ロット（2026年10月4日）

P01・P05・P10・P04・P14・P17の６系統に各12課題、計72課題を実装。既存41ミッションとは異なる課題IDで、星の対象は合計113。図案・条件・設問を独自に作成し、色だけの差し替えによる反復生成は行っていない。

- 体験２・基礎４・応用４・初見用２の順を案内し、全課題を自由に選べる。３問の短いセット、ひとつやさしい課題、記録からのおすすめ、既存ラボへの接続を用意。
- 形の特徴、向き・色・大きさの分離、２～４片の合成、見る人を指定した位置条件、まとまり・向き・大きさの規則、長さと配置の違い、立体の構成へ段階を変える。
- 合成は凸な目標・ピースに限定し、はみ出し・重なりがなく目標を覆う全配置を正解にする。位置、規則、長さの選択でも条件に合う複数候補を認める。
- 積み木の前半は座標一致、最後の２課題は表示した２投影への一致で採点する。支持・範囲・重複を検証し、非表示の投影や特定の元モデルを正解の条件に加えない。例の見本を開く操作は支援として記録する。
- 図形の操作・回答は右側に置く。選択・方向ボタン・90度回転・盤面タップでピースを動かし、積み木は９マスのボタンで積む・取る。ドラッグは必須にしない。

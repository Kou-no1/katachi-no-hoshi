# カタチのほし

図形を「予想する → 動かす・作る → たしかめる」ための学習ゲームです。就学前の入口６系統72課題と、既存の６ラボ41ミッション、計113の星対象課題を遊べます。

## 遊べる内容

- **はじめのかたちあそび**：同じ形、ピース構成、位置、規則性、長さ比較、積み木の６系統。各12課題を「体験２・基礎４・応用４・初見用２」に分け、どこからでも選べます。２段階ヒント、短い３問セット、実物遊び、声掛け、つながるラボへの案内を用意。
- **かたち工房**：２枚の三角形で正方形を埋める／L字のピースを90度回して合わせる。ドラッグ、タップ、移動ボタン、キーボードに対応。
- **ブロック建築**：４・６・８個の３建物を数える・見え方を予想する・見本と同じ場所と高さに作る。制作は３×３の場所ボタンで積む／上の１個を取る操作、取り消し、段と１マスのヒントに対応。
- **自由制作と基地**：３×３×３の範囲で好きな建物を制作。完成した３見本と自由作品１つを、３×３の基地へ配置・移動・90度回転できます。発見に応じて背景を選べます。制作途中と配置を保存し、あとから再開できます。
- **かたちの変身**：対称・拡大縮小・面積、各３課題。鏡の向こうのマスを作り、長さと面積の変化を比べ、１cm²を基準に広さを考える。
- **はこづくり研究所**：検証済みの立方体の展開図３種類で向かい合う面を考える９課題と、直方体の体積・表面積各３課題。
- **３つの図から作る**：正面・右側面・上面の図を満たす建物を復元する３課題。見本と異なる積み方でも、３方向の図に合えば正解。
- **くるくる・切ってみる**：長方形・直角三角形・半円を指定軸で回す３課題と、立方体の切断面が三角形・長方形・正六角形になる３課題。

星の単位は、はじめのかたちあそび72、かたち工房２、ブロック建築６、かたちの変身９、はこづくり15、復元３、回転体・切断６です。ブロックの観察では個数と見え方の両方を確かめて１つの星になります。

ミッションの発見を星としてこのブラウザに保存します。同じミッションで星は重複しません。自由制作には正誤判定や星の加算はありません。作品と制作途中もこのブラウザに保存し、保存不可でも同じページ内で遊びを続けられます。名前の入力、アカウント、分析用の外部送信はありません。読み上げは端末の音声機能を使う任意機能です。

入口72課題の学習記録は、星とは別に初回の答え、確認回数、ヒント・観察支援、結果を保存します。初見用課題で誤答してからやり直した正解は、初回の成功として数えません。体験課題を理解の指標に使わず、完成数で習得を断定しません。既存41の記録から、過去の答えや支援使用を推定することもありません。入口課題の制作途中は保存せず、既存の基地・制作途中の保存とは別です。

回転・移動・視点・折り角度の操作欄は、スマートフォンでも図形の右側に配置します。画面の漢字にはルビを付け、ヒントや解答後のメッセージにも適用します。

## 開発・確認

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/` を静的Webサーバーで配信できます。ビルド後はThree.jsなどの実行コードも同梱され、外部CDNの読み込みはありません。`index.html` のファイル直接起動ではなくHTTPで開いてください。相対パス設定なので、ドメイン直下・サブディレクトリのどちらでも配信できます。

## 図形の正確さ

平面はSVG、動く立体はThree.jsの正投影で描画しています。画面上の絵を問題ごとに手描きするのではなく、座標モデルから描画と答えを作ります。

- `src/geometry/puzzle.ts`：頂点の回転、面積、重なり、はみ出し、目標との一致。
- `src/geometry/blocks.ts`：整数座標の積み木と正面・側面・上面への投影。
- `src/geometry/construction.ts`：支持された列の追加・削除と、見本の全座標の一致判定。
- `src/geometry/box.ts`：共有辺を軸とする親子の折り畳み。追加の面は親の回転を受け継ぎます。
- `src/geometry/transform.ts`：セル中心の反射、頂点の相似変換、多角形の面積。
- `src/geometry/measure.ts`：単位立方体の個数と、外に露出する単位面の数。
- `src/geometry/reconstruction.ts`：支持された配置と３方向の投影を照合し、複数解を許容。
- `src/geometry/solids.ts`：指定軸での掃引メッシュ、立方体の辺と平面の交点から断面を生成。
- `src/geometry/base.ts`：作品の90度回転と、配置の範囲・重複防止。
- `src/learning/content-a.ts` / `content-b.ts`：72課題の幾何・指示・ヒント・実物遊びと採点。凸ピースの被覆、位置条件、回転対称性を含む規則、同率の長さ、２投影の複数解を扱います。
- `src/learning/records.ts` / `legacy.ts`：端末内の試行記録と推薦、既存41ミッションの安定ID・能力タグ。

テストは独立した期待座標・面の組み合わせとも照合します。詳細は [試作仕様](docs/PROTOTYPE.md) と [品質確認表](docs/QA.md) を参照してください。

## 現時点の範囲

これは操作と図形表示を評価しながら育てている初期版です。課題は有限の固定セットで、42系統504課題の拡張計画のうち、最初の６系統72課題を実装しています。残りの教材、自動出題、後日の再確認、任意の展開図・回転軸・切断平面、全学年の問題の網羅、先生用の個人別成績管理は未実装です。学習効果は子どもによる観察・新しい課題での確認が必要です。

立体の自由回転にはWebGL2が必要です。使えない場合、積み木・回転体・切断は固定方向のSVG図で操作・採点を続けられます。箱は平面の展開図と面の予想課題を残し、動く表示が使えないことを画面に案内します。ラボは必要なときに読み込み、最初の平面遊びでは立体用の描画コードを読み込みません。

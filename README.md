# カタチのほし

図形を「動かす → 予想する → たしかめる」ための、３つの学習ラボの試作です。

## 遊べる内容

- **かたち工房**：２枚の三角形で正方形を埋める／L字のピースを90度回して合わせる。ドラッグ、タップ、移動ボタン、キーボードに対応。
- **ブロック建築**：４・６・８個の積み木からなる３つの建物。回転と前・右よこ・上の視点、数える課題、見え方の予想、１段ずつ見るヒント。
- **はこづくり研究所**：検証済みの立方体の十字展開図１種類。スライダーとアニメーションで折り、３組の向かい合う面を考える。

ミッションの発見を星としてこのブラウザに保存します。同じミッションで星は重複しません。名前の入力、アカウント、分析用の外部送信はありません。読み上げは端末の音声機能を使う任意機能です。

## 開発・確認

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/` を静的Webサーバーで配信できます。ビルド後はThree.jsなどの実行コードも同梱され、外部CDNの読み込みはありません。`index.html` のファイル直接起動ではなくHTTPで開いてください。相対パス設定なので、ドメイン直下・サブディレクトリのどちらでも配信できます。

## 図形の正確さ

平面はSVG、動く立体はThree.jsの正投影で描画しています。画面上の絵を問題ごとに手描きするのではなく、座標モデルから描画と答えを作ります。

- `src/geometry/puzzle.ts`：頂点の回転、面積、重なり、はみ出し、目標との一致。
- `src/geometry/blocks.ts`：整数座標の積み木と正面・側面・上面への投影。
- `src/geometry/box.ts`：共有辺を軸とする親子の折り畳み。追加の面は親の回転を受け継ぎます。

テストは独立した期待座標・面の組み合わせとも照合します。詳細は [試作仕様](docs/PROTOTYPE.md) と [品質確認表](docs/QA.md) を参照してください。

## 現時点の範囲

これは操作と図形表示を評価する試作です。自由な基地建築、任意の展開図、斜め切断、回転体、全学年の問題、先生用の個人別成績管理は未実装です。学習効果は子どもによる観察・新しい課題での確認が必要です。

立体の自由回転にはWebGL2が必要です。使えない場合、積み木は固定方向の図で遊べます。箱は平面の展開図と面の予想課題を残し、動く表示が使えないことを画面に案内します。
